# Ojeada a preguntas de Bootcamp de Mercado Libre de los ultimos 3 años

```
cuales fueron las preguntas tecnicas para el bootcamp de mercado libre de los ultimos 3 años
```

Sí. Revisé experiencias publicadas por candidatos de Mercado Libre y, tomando como referencia los últimos 3 años con información disponible (principalmente 2024, 2025 y 2026, y algunos reportes de 2023 para completar el patrón), hay bastante coincidencia en los temas.

Importante: no existe un listado oficial de preguntas de Mercado Libre y las preguntas cambian según el track (Backend, Frontend, Android, etc.) y el entrevistador. Lo siguiente son preguntas/temas reportados por candidatos, no un examen filtrado.

🟡 Backend — las preguntas que más se repiten
1. Programación y algoritmos

En el challenge de HackerRank aparecen ejercicios de programación relativamente básicos/intermedios:

Dar vuelta un String.
Filtrar elementos de un array.
Recorrer y transformar arrays.
Resolver un problema utilizando estructuras de datos.
Determinar la complejidad temporal de un algoritmo.
Diferenciar búsqueda vs. ordenamiento.
Analizar qué devuelve determinado código.
Trabajar con arrays, listas y associative arrays/maps.
Resolver ejercicios y justificar por qué una solución es mejor que otra.

En 2024, por ejemplo, un candidato reportó un ejercicio de invertir un string/filtrar un array y otro relacionado con conectarse a una API y serializar datos.

2. Git

Aparecen preguntas del estilo:

¿Qué hace git clone?
¿Cuál es la diferencia entre git merge y git rebase?
¿Cómo deshacés un commit?
¿Qué comando utilizarías en determinada situación?
¿Qué diferencia hay entre git pull y git fetch?
¿Qué significa tener conflictos y cómo los resolverías?

En las pruebas recientes se reportaron específicamente preguntas de Git donde había que elegir qué comando utilizar en diferentes situaciones.

3. HTTP / REST / APIs

Este es uno de los bloques que más consistentemente aparece.

Preguntas reportadas:

¿Qué es una API?
¿Qué es REST?
Diferencia entre GET, POST, PUT, PATCH y DELETE.
¿Cuándo usarías GET vs. POST?
¿Qué significan los códigos HTTP 200, 400 y 500?
¿Qué diferencia hay entre un error 4xx y uno 5xx?
¿Qué significa que una API sea RESTful?
¿Cómo consumirías una API?
¿Cómo serializar/deserializarías un JSON?

Los reportes de 2022-2025 siguen mencionando HTTP, REST, métodos HTTP y APIs como parte central del challenge.

4. POO / Java

Para Backend Java aparece:

¿Cuáles son los 4 pilares de la programación orientada a objetos?
Explicá encapsulamiento.
¿Qué es herencia?
¿Qué es polimorfismo?
¿Qué es abstracción?
¿Cuál es la diferencia entre una clase y un objeto?
¿Qué diferencia existe entre interface y abstract class?
¿Qué es overriding?
¿Qué es overloading?
¿Qué diferencia hay entre break y return?
¿Qué sucede cuando ejecutás determinado código?

En una experiencia de 2024 se reportaron específicamente preguntas sobre OOP, herencia, break, return, bases de datos y NoSQL.

Reddit

Y en una experiencia de Java de 2025 aparece explícitamente un cuestionario sobre los pilares de OOP y cómo se aplican en Java, además de SQL y dos ejercicios de HackerRank.

5. Bases de datos / SQL

También se repite bastante:

¿Qué es una base de datos relacional?
¿Qué es una clave primaria?
¿Qué es una foreign key?
Diferencia entre INNER JOIN, LEFT JOIN, etc.
Escribir una query SQL.
¿Qué es normalización?
¿Qué diferencia existe entre SQL y NoSQL?
¿Cuándo utilizarías una base NoSQL?
¿Qué ventajas/desventajas tiene una BD relacional?

Un candidato de 2022 reportó que le hicieron hacer una query y conversar sobre bases de datos; experiencias de 2024-2025 también mencionan DB/SQL y NoSQL.

🎯 Las 20 preguntas que yo practicaría

Si tu objetivo es pasar la entrevista técnica del Bootcamp Backend, practicaría respondiendo oralmente estas:

¿Cuáles son los cuatro pilares de POO?
¿Qué diferencia hay entre encapsulamiento y abstracción?
¿Qué diferencia hay entre herencia y composición?
¿Qué es polimorfismo?
¿Interface vs. clase abstracta?
¿Qué diferencia hay entre break y return?
¿Qué es un HashMap y cuándo lo utilizarías?
¿Cuál es la complejidad de buscar un elemento en un array?
¿Cuál es la complejidad promedio de buscar en un HashMap?
¿Qué diferencia hay entre un array y una lista?
¿Qué diferencia hay entre GET y POST?
¿Qué significan HTTP 200, 400, 401, 404 y 500?
¿Qué es una API REST?
¿Qué es JSON y cómo lo serializarías/deserializarías?
¿Qué diferencia hay entre INNER JOIN y LEFT JOIN?
¿Qué es una primary key y una foreign key?
¿SQL vs. NoSQL?
¿Qué diferencia hay entre git merge y git rebase?
¿Monolito vs. microservicios?
Te dan un código y te preguntan qué devuelve y cuál es su complejidad.

Esto último es particularmente importante porque los reportes muestran que no se limitan a preguntas de memoria: también buscan que puedas leer código, razonar y explicar tu solución.
